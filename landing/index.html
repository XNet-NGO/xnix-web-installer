X-NIX

A hardened, GrapheneOS-derived mobile OS for the Pixel 10 Pro XL — signed with its own keys, a curated privacy app suite, and self-hosted updates.

Install in your browser CLI install guide

What it is

X-NIX is built on the GrapheneOS hardened Android base and compiled from source for the Pixel 10 Pro XL (codename mustang). It keeps GrapheneOS's security model — verified boot, a strong sandbox, and hardware-backed attestation — while shipping its own signing keys, a bundled app set, and two small privileged helper services.

Built on

Verified boot, your key

Signed end-to-end with X-NIX keys; the bootloader locks to the X-NIX AVB root of trust.

Attestation-safe

Identity is rebranded for display only — the build fingerprint stays intact so hardware attestation keeps working.

Curated app suite

A set of privacy and utility apps preinstalled out of the box, no Google services required.

Privileged helpers

Two minimal native services (interface-pinned networking + a Shizuku-free terminal helper), each in its own SELinux domain.

Self-hosted updates

Over-the-air updates delivered from ota.foxnet.live, verified against the baked-in signing key.

Browser install

Flash directly from a WebUSB browser — no SDK, no command line required.

Install

You need a Pixel 10 Pro XL with an unlockable bootloader and a USB cable.
