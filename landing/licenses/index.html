X-NIX is built from open-source software. This page provides the required license notices and points to the corresponding source, in compliance with those licenses.

Upstream projects

X-NIX is derived from the GrapheneOS project, which is itself based on the Android Open Source Project (AOSP). X-NIX is an independent build and is not affiliated with, endorsed by, or supported by the GrapheneOS project or Google.
